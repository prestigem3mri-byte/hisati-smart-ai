# حصتي الذكية AI

نسخة Next.js جاهزة للنشر على Vercel.

## التشغيل محليًا
1. ثبتي Node.js.
2. افتحي مجلد المشروع في Terminal.
3. `npm install`
4. انسخي `.env.example` إلى `.env.local` وضعي مفتاح OpenAI.
5. `npm run dev`
6. افتحي `http://localhost:3000`

## Vercel
ارفعي المشروع إلى GitHub ثم Import في Vercel. في Settings → Environment Variables أضيفي:
- `OPENAI_API_KEY` = مفتاحك
- `OPENAI_MODEL` = اختياري، والافتراضي `gpt-5-mini`
ثم Redeploy.

## ما يعمل
- إنشاء بنك أسئلة من عنوان الدرس فقط، أو النص، أو صور صفحات الدرس.
- 3 مستويات: مبتدئ / متوسط / متقدم، مع إجابة وتلميح.
- استخراج أسماء الطالبات من صورة السجل ومراجعتها قبل الاستخدام.
- عجلة دوارة مرتبطة بمستوى الطالبة.
- مؤقت 5 / 7 / 10 دقائق.
- تقرير حصة قابل للطباعة والحفظ PDF.
- حفظ البيانات محليًا على جهاز المعلمة.
